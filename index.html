PROJECT ARCHITECTURE

AirGuard System Design

AirGuard integrates hardware gas and particulate matter sensors with microcontroller interfaces to aggregate continuous air quality telemetry. The web application ingests streaming metrics to plot live environmental health indicators.

1. Hardware Layer: Sensor array capturing atmospheric particulate matter (PM2.5, PM10) and ambient carbon monoxide / gas concentration.
2. Telemetry Processing: Real-time ADC sampling, smoothing window calculation, and AQI category classification.
3. Web Interface: Reactive browser dashboard rendering real-time animated waveforms, gauge meters, and alert thresholds.
